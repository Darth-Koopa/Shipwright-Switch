## 开启网络功能（ENABLE_REMOTE_CONTROL）
- 用户按游戏内提示 "The Network features are unavailable because SoH was compiled without network support (\\"ENABLE_REMOTE_CONTROL\\" build flag)" 要求打开。
- 机制：真正的 CMake 开关是 `BUILD_REMOTE_CONTROL`（soh/CMakeLists.txt 用它向编译器传 `ENABLE_REMOTE_CONTROL` 宏，并控制 `crowd-control/` 目录是否编入、以及链接 `SDL2_net::SDL2_net-static`）。之前 `build_config.bat` 的 cmake 命令**没传**该开关，故默认关闭。
- 依赖：`find_package(SDL2_net)` 若找不到会自动 `set(BUILD_REMOTE_CONTROL 0)` 禁用（CMakeLists.txt:312-321）。确认 `SDL2_net` 已通过 vcpkg 装好（`build/x64/vcpkg/installed/x64-windows-static/`，`SDL2_net-static.lib` + `SDL2_netConfig.cmake`）。
- 改动：`build_config.bat` 的 cmake 命令加 `-DBUILD_REMOTE_CONTROL=ON ^`（在 `-DINCLUDE_MPQ_SUPPORT=OFF ^` 之后）。
- 流程：先后台跑 `build_config.bat`（重新 configure）→ 确认 `BUILD_REMOTE_CONTROL:UNINITIALIZED=ON` 写入 CMakeCache，且 `SDL2_net_DIR` 指向 vcpkg；**无** "Disabling BUILD_REMOTE_CONTROL" 消息 → SDL2_net 找到。再后台跑 `run_build.ps1`（全量重编译，因 ENABLE_REMOTE_CONTROL 是全局宏导致上千文件重编 + 链接 SDL2_net）。
- 结果：**BUILD_RC_0 成功**，生成 `x64/Release/soh.exe`，`Network.cpp`/`SohMenuNetwork.cpp` 已编入，无任何 error（仅代码既有 warning）。网络/Remote Control/Sail 功能已启用。
- 注意：重新 configure 后必须重新 build 才会生效；`.bat` 改的是 configure 阶段，run_build.ps1 只 build 不 configure。
