## CMake GLOB 坑：新增源文件后必须重跑 configure（2026-07-16）
- `soh/CMakeLists.txt:124` 用 `file(GLOBRECURSE soh__ ... "soh/*.cpp" ...)` 收集源文件。**GLOB 只在 CMake 配置（configure）时扫描一次**，之后新增的 `.c/.cpp`（如后来生成的 `soh/soh/z_staff_CHI.cpp`）不会自动进构建。
- 首次 `cmake --build` 会因该 `.cpp` 里定义的 `sChiStaffMessageEntryTablePtr`（被 `z_message_PAL.c` 引用）未编译而**链接失败 LNK2001/LNK1120**。
- **解法**：新增源文件后先跑 `run_configure.bat`（重跑 GLOB），再 `run_build.bat`。`run_build.bat` 只 build 不重新 GLOB，不能靠它自动拾取新文件。
- 同理 `run_gen_o2r.bat` 只打包资源，不含 C 代码；代码改动需单独 build 才生效。
- 踩坑：首次新增 custom 文件夹后立即生成，custom OTR 可能瞬时漏打包该文件夹；删全部 soh.o2r 重跑一次即可。已记入 MEMORY.md。
